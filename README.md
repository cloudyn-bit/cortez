# ⚡ LifeOS

> **Your Productivity Companion**

LifeOS is a modern, all-in-one productivity operating system designed to help students, developers, creators, and professionals manage every aspect of their workflow from a single dashboard.

Built with a premium, minimal interface inspired by Apple's Human Interface Guidelines, Linear, Arc Browser, and Vercel, LifeOS combines task management, habit tracking, goal planning, note taking, focus sessions, and productivity analytics into one seamless experience.

### 🤖 Cortez

Meet **Cortez**, the built-in productivity companion.

Unlike traditional AI chatbots, Cortez works using contextual awareness generated from your own productivity data.

Cortez can:

- Provide personalized productivity insights
- Suggest useful actions
- Display reminders
- Surface habit streaks
- Highlight important deadlines
- Help you stay focused throughout the day

## 💾 Data Storage

LifeOS stores user data locally in the browser using Local Storage.

This includes:

- Tasks
- Habits
- Goals
- Notes
- Pomodoro sessions
- User preferences

No external backend is required for the MVP.
